# 盤上大戦 — スマホ縦画面 Web 試作版

チェス・将棋・チェッカー・オセロを混合する、10×10盤の対戦ゲームです。

## 起動方法

`index.html` をブラウザで開くか、ローカルサーバーで起動します。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。サーバー方式を推奨します。

## GitHub Pages で公開する

1. このフォルダー内の `index.html`、`assets/`、`README.md` を GitHub リポジトリのルートへアップロードします。
2. GitHub の **Settings → Pages** で **Deploy from a branch** を選択します。
3. Branch を `main`、Folder を `/(root)` にして保存します。
4. 発行された URL をスマートフォンで開きます。

ビルドコマンドや外部依存パッケージはありません。GitHub へのアップロード・公開操作は利用者側で行います。

## ファイル構成

```
index.html                   画面のHTML構造
assets/css/main.css         画面共通デザイン
assets/css/board.css        共通10×10盤・駒の見た目
assets/js/state.js          駒定義・デッキデータ・ゲーム状態
assets/js/core.js           プリセット・共通処理
assets/js/navigation.js     画面切替・ダイアログ
assets/js/editor.js         デッキ編集・配置編集
assets/js/setup.js          対戦開始準備
assets/js/rules.js          移動・捕獲・配置の合法性
assets/js/battle.js         対局表示・行動・勝敗・簡易CPU
```

JavaScript は依存関係の順に `defer` 読み込みする従来型スクリプトです。ES modules に変更するときは関数の import/export とインラインイベントを整理してください。

## 今回の修正

- 初期配置編集も対戦も共通の **10×10正方形盤** を使用。初期配置では手前3列だけを操作可能にしました。
- 10行10列を明示したCSS Gridで、各マスを等しい正方形にしています。盤の横幅は端末幅に合わせ、どちらの画面でも同じ値を使います。
- チェッカーは **赤・紺の装飾入り円盤（◆、キングは♛）**、オセロは **無地の白黒石** にしています。
- ローカル対戦・簡易CPU、盤面選択、手持ち、デッキ編集を保持しています。

## 現状の注意

これはルール検証向けの試作品です。すべての稀なルール衝突・CPUの戦略・通信対戦が完成しているわけではありません。とくに将棋の打ち制限、キャスリング、チェッカーの複数捕獲、オセロの複数方向反転の実戦テストを続けてください。

### 想定ルール

- 編成：40コスト以下、12〜30枠、初期盤上8体以上。
- 将棋王・チェスキング：それぞれ最大1体。捕獲・寝返りされると敗北。
- 相手の盤上駒を0体にすると即勝利（手持ちがあっても敗北）。
- 制限：双方40手、盤上の通常駒1点・王系5点で判定。
- オセロ：手持ちから配置。新しく置いた自軍オセロ石と既存の自軍オセロ石の間にある **空きなしの連続敵駒だけ** を寝返らせます。

## 今後の開発指針

- `rules.js` と `battle.js` のゲーム状態変更処理を段階的に純粋関数へ分離し、自動テストを追加する。
- ローカル対戦とオンライン対戦で同一の合法手処理を共有する。
- 履歴・リプレイ・UI描画をゲームロジックから分離する。
- 操作しやすさや駒の識別性を実機で継続確認する。
